Predict which employees are most likely to quit their jobs and identify the top driving factors.

This project serves as an end-to-end implementation of applying **Decision Trees** to a real-world dataset to extract insights and build a predictive model.

## 🎯 Objective
The primary goal of this project is to build a robust Machine Learning pipeline that effectively addresses the problem statement using **Decision Trees**. This involves data preprocessing, exploratory data analysis (EDA), feature engineering, model training, and evaluation.
