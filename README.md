## 🌟 Overview

This repository contains fully implemented machine learning projects. Each project comes with its own dataset, models, exploratory data analysis (EDA), and a deployment application (like a Streamlit web app).

---

## 📁 Projects Map

- 📧 **`E-mail_Spam/`**
  - Spam detection system built with classic ML algorithms (Naive Bayes, SVM, Logistic Regression).
  - Includes a Streamlit web application to test emails in real-time.

- 💬 **`SMS_Spam/`**
  - SMS spam classification dataset and models.

---

## 🚀 Getting Started

1. **Clone the Repo:** Open this repo in VS Code.
2. **Environment Setup:** Create a virtual environment and install the required dependencies (Python 3.9+).
3. **Run the Apps:** Navigate to the specific project directory and run the deployment script.
   ```bash
   cd E-mail_Spam
   streamlit run app.py
   ```
