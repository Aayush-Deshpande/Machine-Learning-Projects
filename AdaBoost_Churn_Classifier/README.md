## 🔎 Project Overview
Predict customer churn or retention using AdaBoost boosting algorithms.

This project serves as an end-to-end implementation of applying **AdaBoost Classifier** to customer accounts and usage data to build a strong classifier out of sequential weak learners.

## 🎯 Objective
The primary goal of this project is to build a robust Machine Learning pipeline that effectively addresses the problem statement using **AdaBoost Classifier**. This involves data preprocessing, handling class imbalances, model training with adaptive boosting weights, tuning learning rate and estimators, and evaluation.
