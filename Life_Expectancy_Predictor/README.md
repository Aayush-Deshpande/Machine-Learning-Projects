## 🔎 Project Overview
Predict life expectancy based on health, economic, and social development indicators using Gradient Boosting.

This project serves as an end-to-end implementation of applying **Gradient Boosting Regressor** to global country-wise metadata to build an ensemble regression model that corrects residual errors sequentially.

## 🎯 Objective
The primary goal of this project is to build a robust Machine Learning pipeline that effectively addresses the problem statement using **Gradient Boosting Regressor**. This involves data preprocessing (imputing country statistics, scaling features), exploratory data analysis (EDA), model training, hyperparameter optimization, and evaluating feature importances.

## 🧠 Algorithm Used
